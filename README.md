## Try it in five minutes

1. Copy `file-access.md` into your agent's skill folder.
2. Edit the placeholder paths: name your allowlisted folders (at most 10) and your work folder.
3. Run one small task in a throwaway workspace first — find a file, copy it, read the log it writes.
4. If it behaves, promote it to your real setup. That test-first order is the whole method.

## Why these fences

We run our own agent, KITT, every day. This pack is built from that daily use — sandbox-first testing, allowlists, a code-gate, and spend caps learned from real breaks, not theory. An agent with no caps will eventually loop, an agent with no allowlist will eventually wander, and an agent with no log will leave you guessing. The fences here turn those surprises into small, logged, fixable events.

## Honest limits — read before you rely on this

- **No safety guarantee.** These files reduce common risks with fences, caps, and logs. They do not make any agent "safe," and no instruction file can.
- **Not hack-proof, not compliance.** This is not a security audit, not a compliance tool, and not a promise that your setup meets any law, standard, or workplace policy.
- **No set savings promised.** Caps can stop a runaway loop from becoming a huge bill, but we do not promise any amount of savings. Your usage, your provider, your bill.
- **Closed agents can't use everything.** Agents that will not accept custom skill files cannot use the skills at all, and closed agents that lock their model route cannot use the token-burn tooling. File names, folders, and settings also differ between platforms — the adapter sheets in the full Vault cover the conversion, but expect some setup time.
- **Your agent, your responsibility.** You stay responsible for your own setup, your own accounts and keys, what you allowlist, and what your agent does. Test in a sandbox, read your logs, keep your caps honest.
- **Examples are fake on purpose.** Every name, address, and path in these files is a placeholder. Replace them with your own values during setup — and never paste real keys or passwords into a skill file or a chat.
